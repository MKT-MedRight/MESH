Push this browser's data to Firebase
Use this once, from the machine that holds the real library, to seed the database. After that everything syncs by itself.
Until this is connected, every browser keeps its own copy — a policy you publish here never reaches an employee, and their questions never reach you. Three steps, about ten minutes, no code:
1
At console.firebase.google.com, create a project, then Build → Firestore Database → Create database (production mode, region eur3). In its Rules tab, paste the rules below and Publish. 
{{ rulesText }}
2
Then Project settings → Your apps → Web app. Copy the whole firebaseConfig block Firebase shows you and paste it here:
Build my firebase-config.js
{{ cfgMsg }}
3
Put the downloaded firebase-config.js in your repository, replacing the empty one, and commit. Reload the live site — this card turns green, and you press Push this browser's data once to seed the library.
{{ fileCardTitle }}
